# 121. 요그제바 앙크 부활 버그 수정

## 문제
요그제바(최종 보스)와 전투 중 사망 후 일반 앙크로 부활하면 보스가 사라져서 게임 진행이 불가능해지는 버그가 있었습니다.

## 원인
HallsBossLevel.java의 `occupyCell()` 메서드에서 보스 스폰 조건이 `bossScores[4] == 0`으로 설정되어 있었습니다.

점수 흐름:
- 0: 보스 전투 시작 전
- 음수: 전투 중 (요그제바 광선에 맞을 때마다 -500)
- 양수 (5000+): 보스 처치 후

일반 앙크 사용 시 새 레벨이 생성되지만 점수는 음수 상태로 유지됩니다. 기존 코드는 점수가 정확히 0인 경우에만 보스를 스폰하므로, 음수 점수 상태에서는 보스가 스폰되지 않았습니다.

## 수정 내용
- `Statistics.bossScores[4] == 0` → `Statistics.bossScores[4] <= 0`
- 점수가 0 이하(전투 시작 전 또는 전투 중)일 때 보스가 스폰되도록 변경
- 보스 처치 후(점수 양수)에는 여전히 스폰되지 않음

## 기술적 세부사항
- 파일: `core/src/main/java/.../levels/HallsBossLevel.java`
- 원본 Shattered Pixel Dungeon 3.3.8에는 이 점수 체크 자체가 없었음
- 보스 처치 여부 확인 로직의 조건문 오류
- 코드베이스 전체 검토를 통해 의도치 않은 부작용이 없음을 확인

## 영향
- 요그제바 전투 중 일반 앙크 사용 시 정상적으로 보스가 재스폰됨
- 게임 진행 불가 버그 해결
